## 投影片 14-1 — 篩檢一種不夠？檢查工具總覽（新增）
- **場景引子：** 收到複檢通知先別慌，加做不是壞消息，是換放大鏡再看一次。
- **篩檢入口（沒症狀、40-74 歲每 2 年）：** 乳房 X 光攝影（見 P11）
- **回診加做（有原因才加，不是人人都要）：**
  1. 乳房超音波——攝影 0 類、緻密乳房、有症狀、年輕／懷孕哺乳的補充
  2. 放大／局部壓迫攝影——鈣化點或局部病灶要放大判讀
  3. 乳房斷層合成攝影 DBT（tomosynthesis／3D）——組織重疊看不清、緻密乳房釐清
  4. 乳房 MRI——高風險（BRCA／強家族史）、術前看範圍、多發或難判讀、植入物問題、治療反應評估
- **分流地圖：** 0 類先加超音波或放大 → 緻密／重疊加斷層 → 高風險／術前／難判讀加 MRI；1、2 不用回；3 追蹤可搭配超音波
- **比喻：** 攝影是全機掃毒，加做是對可疑檔案按右鍵再掃一次。
- **帶得走金句：** 篩檢用攝影，加做有原因
> **講者指引：** 這頁只給地圖不給恐懼。先說「加做＝更仔細，不是更嚴重」，再帶下一頁比較表。

## 投影片 14-2 — 加做四種檢查：時機 × 做法 × 優缺點（新增）
- **場景引子：** 超音波要塗凝膠？MRI 要打針躺 30 分鐘？一次講清楚就不怕。

| 檢查 | 什麼時機加做 | 如何進行 | 優點 | 缺點／注意 |
|------|-------------|---------|------|-----------|
| 乳房超音波 | 攝影 0 類釐清；緻密乳房補充；摸到硬塊、有症狀；年輕、懷孕哺乳優先 | 躺床塗凝膠，探頭滑動掃描約 10-15 分，無輻射 | 無輻射；分囊腫或實心；緻密乳房的加成工具；可即時導引切片 | 看不到微小鈣化；結果較依賴操作者；偽陽性偏高；不適合單獨做大規模篩檢 |
| 放大／局部壓迫攝影 | 鈣化點形態難判讀；局部病灶要壓開重疊組織再看 | 針對局部加壓、放大再拍 1-2 張，數分鐘完成 | 鈣化形態看得更清楚；減少不必要的切片；流程快 | 需再次壓迫；額外低劑量 X 光；仍會不適 |
| 乳房斷層合成 DBT（3D） | 組織重疊疑似假影；緻密乳房釐清；降低召回 | 姿勢同一般攝影，X 光管弧形多角度掃描數秒，重組成薄切面 | 減少重疊遮蔽；降低召回率；緻密乳房偵測提升 | 輻射略高於 2D 但仍屬低劑量；時間稍長；非每家都有；可能自費 |
| 乳房 MRI | 高風險族群補充篩檢；術前看範圍／多發／對側；植入物破裂懷疑；新輔助治療反應評估 | 俯臥、乳房垂入專用線圈，打顯影劑約 30-40 分，噪音大需配合閉氣 | 無輻射；敏感度最高；看範圍、多發、對側最清楚 | 費用高、多自費；偽陽高易加做切片；顯影劑需評估腎功能／過敏；幽閉恐懼、金屬植入禁忌；需預約、時間長 |

- **帶得走金句：** 工具各有位，對症才有效
> **講者指引：** 用「對症派工」收束：超音波看結構、放大看鈣化、斷層解重疊、MRI 看範圍。呼應 P14 分流：0、4、5 立即回乳房專科由醫師派工，病人不用自己點菜。
> **講者指引：** 降低聽眾對「異常」的恐懼。強調跟公司做 code review 發現 bug 一樣——發現得越早，修復成本越低

## 投影片 15 — 乳癌警訊症狀（自我檢查）
**七大警訊：**
- 乳房 / 腋下 **摸到硬塊**
- **乳頭凹陷** 或 **異樣分泌物**（帶血）
- 乳房 **局部凹陷** 或 **凸出**
- 乳房皮膚 **橘皮樣變化**、發紅、潰爛
- 腋下 **淋巴結腫大**
- **形狀或大小改變**
- 持續 **疼痛**（少數案例）

> 即使攝影檢查正常，出現上述異狀 **仍應就醫**
> **講者指引：** 可以搭配圖片/圖示。強調「你比任何人更了解自己的乳房，有異常就去看醫生」

## 投影片 16 — 乳房自我檢查 step by step
**三個步驟（每月 1 次，經期後一週）：**

**① 鏡前看**
- 雙手自然下垂 → 再高舉過頭
- 觀察外觀：凹陷、凸起、不對稱

**② 洗澡觸**
- 手指指腹（非指尖）以 **螺旋狀** 按壓全乳
- 範圍：鎖骨 → 乳房下緣 → 腋下

**③ 平躺摸**
- 同側肩膀下墊枕頭
- 用對側手重複螺旋按壓

> **講者指引：** 可用影片或現場示範。但要強調：**自我檢查不能取代乳房攝影**，兩者要並行！

## 投影片 17 — 如果真的遇到——乳癌不是絕症
- **早期（0+1 期）乳癌**：5 年存活率 **近 100%**
- **第 2 期**：95.6%
- **第 3 期**：80.5%
- **第 4 期**：39.4%

> 透過篩檢發現的個案 → **59.7% 屬於早期**
> 未篩檢才發現 → 早期僅 **33.4%**

**結論：** 決定存活率的關鍵不是「會不會得」，而是 **「第幾期才發現」**

**期別如何區分（民眾版白話）：**
| 期別 | 白話解釋 |
|------|---------|
| 0 期 | 原位癌，還在乳管/乳小葉裡，沒跑出去 |
| 1 期 | 腫瘤 <2cm，淋巴多半沒被侵犯 |
| 2 期 | 腫瘤 2-5cm，或附近少數淋巴有癌 |
| 3 期 | 腫瘤較大、多顆淋巴有癌，或侵犯皮膚/胸壁 |
| 4 期 | 已遠端轉移（骨、肺、肝、腦等） |

> 詳細分期由醫師依腫瘤大小、淋巴、轉移（TNM）判定，此處只為建立概念：越早越小、越侷限，越好處理。
> **講者指引：** 翻轉「癌症＝絕症」的印象。用對比數據讓聽眾理解篩檢的價值
